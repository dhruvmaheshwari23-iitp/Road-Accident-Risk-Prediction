# Road Accident Risk Prediction

## Overview
A machine learning project developed for the Kaggle Playground Series competition, *Predicting Road Accident Risk*. The objective is to predict accident risk using the provided road-related dataset.

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- LightGBM
- Matplotlib

## Approach
- Data loading and preprocessing
- Categorical feature handling
- Machine learning model training
- Cross-validation and model evaluation
- Prediction generation and Kaggle submission

## Evaluation
The competition uses a prediction error metric. Model performance is evaluated using validation results and the Kaggle public leaderboard.

## How to Run
1. Download or clone this repository.
2. Open the Jupyter notebook.
3. Install the required Python libraries.
4. Run the notebook using the competition dataset available on Kaggle.
